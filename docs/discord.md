# Discord での利用方法

TRPG-Voice-Bridge は、生成音声を参加者が開いている/playerのページに配信して再生しますが、Discordなどのボイスチャットを併用している場合、ボイスチャットのマイクで拾った再生音声が、環境によってはエコーとなって聞こえることあります。

このような場合は、/player 側の設定で音声の再生を停止あるいは音量を小さくするか、ここで説明している Discord のボット機能を利用して生成音声を再生することができます。

また、TRPG-Voice-Bridge の /player のページをインターネットに公開したくなかったり、あるいはそれが不可能な場合は、音声担当者のみが/playerのページで全員分のキャラの音声設定を行い、生成音声の出力を、Discord Bot 経由だけに集約することもできます。

## Discord側の準備

まず、Discord のボット機能を利用するために、次の手順でボットを作成してください。

### 手順

1. **サーバーを用意する**
   - Discordに既存のサーバーを使用する場合は、この「サーバーを追加」する準備は必要ありません。
   - Discordで「サーバーを追加」→「オリジナルの作成」を選び、サーバーを作る。
     - 新しく作ったサーバーには、最初からボイスチャンネルがある。
     - サーバーの持ち主には、Botを招待する権限（サーバー管理）がある。
2. **Botを作る**（[Discord Developer Portal](https://discord.com/developers/applications)）
   1. 「New Application」を押し、名前を付けて作成する。名前とアイコンは後から変えられる。
   2. 左のメニューの「Bot」で「Reset Token」を押し、表示されたトークンをコピーする。
      - トークンは一度しか表示されない。なくしたら、もう一度「Reset Token」で作り直す。
      - パスワードや2段階認証の確認を求められることがある。
3. **Botを招待する**
   - 「General Information」の「Application ID」を、次のURLの `<Application ID>` に入れて開く。
     ```
     https://discord.com/oauth2/authorize?client_id=<Application ID>&scope=bot&permissions=3146752
     ```
   - 開いた画面で対象のサーバーを選び、「認証」を押す。
   - 本実装では、この招待URLは管理画面に出る（「管理画面の操作」3）。

### Botの設定と権限

| 場所 | 設定 | 説明 |
|---|---|---|
| **招待URL**（`permissions=3146752`） | チャンネルを見る・接続・発言の3つ | 実際の権限はここで決まる。招待すると、サーバーにBot用のロールが自動で作られ、この3つの権限が付く |
| 「Bot」画面の権限の一覧（Bot Permissions） | 触らない | 招待URLを作るための計算機で、ここで選んでも権限は付かない |
| 「Bot」画面の「Privileged Gateway Intents」 | すべてオフ（初期値） | このBotは使わない（intentsは `Guilds` と `GuildVoiceStates` だけ） |
| 「Bot」画面の「Requires OAuth2 Code Grant」 | オフ（初期値） | オンにすると、上の招待URLでは招待できなくなる |
| 「Bot」画面の「Public Bot」 | オフを推奨 | ほかの人がこのBotを自分のサーバーに追加できないようにする。オフにするときにエラーが出たら、「Installation」の「Install Link」を「None」にしてから試す |
| 「Installation」の初期設定 | 触らない | Discordが用意する招待リンク用の設定。自分で作った招待URLを使うので関係ない |

- **「管理者（Administrator）」は付けない。** トークンが漏れたときに、サーバー全体を操作されてしまう。
- 「メッセージを送信」なども要らない。このBotはチャットを読みも書きもしない。
- **特定の人しか入れないボイスチャンネル**では、Bot用のロールにも、そのチャンネルの「チャンネルを見る」「接続」「発言」を許可する。許可されていないチャンネルは、管理画面で選べない状態になる（「管理画面の操作」4）。誰でも入れる普通のボイスチャンネルなら、何もしなくてよい。

### トークンの扱い

- トークンを知っている人は、Botを自由に操作できますので、取り扱いには注意してください。
- トークンは管理画面から入力し、`data/discord.json`（権限0600）にだけ保存されます。

## TRPG-Voice-Bridge 側の準備

1. tts-bridge で通常どおり npm start。起動ログの管理用リンクを開きます。
2. 「Discord Bot」の三角印を押して詳細を開き、先頭の「Discord Botに接続する」をオンにします。 Botトークンを入力して「保存してログイン」。折りたたみと接続設定は独立しており、折りたたんでも接続は維持します。チェックを外すとBotを停止します。トークンは前述のDiscord の Developer Portalの Bot → Reset Token で取得します。General Informationの公開キーとは別です。
3. 必要なら「招待URLをコピー」でBotを招待します。チャンネル一覧は5秒ごとに更新されます。
4. 「ボイスチャンネル」で接続先を選び、「接続」。権限のないチャンネルは選べません。
5. 入室・退出メッセージは、声が未設定なら「聞き取りやすい若い女性ナレーターの声」で生成します。登録済みの声を使う場合は選んで「メッセージを保存」を押します。状態欄で「生成中」「準備済み」「生成失敗」を確認できます。「入室を試聴」「退出を試聴」は管理画面だけで再生します。入室・退出時にも流したい場合は、保存後に接続し直してください。空欄にしたメッセージは流しません。
6. VTTのCollectorを接続し、Playerでキャラの声を設定して、管理画面で「読み上げ開始」を押します。
